# Energy Trading Between Households

## 📌 Project Description
This project enables decentralized energy trading between households using a blockchain-based smart contract. Households with surplus energy (e.g., from solar panels) can list it for sale, while others can purchase the energy directly without intermediaries.

## 🎯 Project Vision
To promote sustainable and decentralized energy systems by empowering households to participate in a transparent, secure, and peer-to-peer energy trading ecosystem using blockchain technology.

## ✨ Key Features
- Households can **list excess energy** for sale at their own prices.
- Others can **purchase energy directly** from sellers using ETH.
- Fully **transparent and trustless** smart contract on Ethereum.
- Emits events for **energy listing and purchase** for easy tracking.

## 🔮 Future Scope
- Integration with IoT devices for **real-time energy data**.
- Implementation of **dynamic pricing** and bidding systems.
- Support for **tokenized energy credits** (ERC20).
- Deployment on **scalable Layer 2 solutions** for reduced gas costs.
- Development of a **user-friendly DApp interface**.
